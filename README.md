# Базовый RAG-агент (Pinecone + LangChain)

Учебный проект.

## Что реализовано

1. **Подключение к Pinecone** — класс `RAGAgent` в `rag_agent.py` подключается к векторному
   хранилищу и при необходимости создаёт индекс (`cosine`, размерность по модели эмбеддингов).
2. **Обработка URL** — `RAGAgent.add_url(url)`: загрузка страницы → очистка HTML
   (BeautifulSoup) → разбиение на чанки (`RecursiveCharacterTextSplitter`, 1000/150) →
   эмбеддинги OpenAI → запись в Pinecone. ID чанков детерминированы, повторная индексация
   страницы не создаёт дубликатов.
3. **Реальный GET-запрос к API** — инструмент `create_api_request_tool` (`@tool`) вместо заглушки
   запрашивает случайный факт о кошках у открытого API <https://catfact.ninja/fact>;
   обрабатываются таймаут, HTTP-ошибки, невалидный JSON и неожиданный формат ответа.
4. **Агент** — `RAGAgent.ask(вопрос)`: LangChain-агент сам решает, искать ли в базе,
   читать ли URL или вызвать API.
5. **Тестовая проверка** — `python rag_agent.py` проверяет подключение к Pinecone,
   выполняет тестовый поиск и вызывает API-инструмент.

## Запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # впишите свои ключи
python rag_agent.py         # тест подключения
python demo.py https://en.wikipedia.org/wiki/Earth "Какой радиус Земли?"
```

Нужны ключи OpenAI (или совместимого провайдера через `OPENAI_BASE_URL`) и Pinecone.

## Структура

| Файл | Назначение |
|------|-----------|
| `rag_agent.py` | класс `RAGAgent`, инструменты, тестовая точка входа |
| `demo.py` | индексация URL и вопрос агенту |
| `test_offline.py` | офлайн-тесты (парсинг/чанки/API) без ключей |
| `.env.example` | пример переменных окружения |
